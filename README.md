# Планета Земля — 3D-симулятор

> Интерактивный визуальный симулятор Солнечной системы с акцентом на Землю: реалистичные пропорции, смена дня и ночи, сезоны, фазы Луны, облака, атмосфера, огни городов.

## ✨ Возможности

- **Реалистичные пропорции** — Солнце (R=109), Земля (R=1), Луна (R=0.273)
- **Смена дня и ночи** — динамическое освещение, плавный переход
- **Сезоны** — годовое вращение, автоматический расчёт температуры по месяцам
- **Фаза Луны** — новолуние → полнолуние, приливный захват (1 оборот за орбиту)
- **Облака** — отдельный слой с регулировкой интенсивности (0–100%) и скорости (0x–5000x)
- **Атмосфера** — сине-голубое свечение по краям Земли
- **Огни городов** — ночная текстура Земли, видимая в тёмной стороне
- **Звёздное небо** — 6000 точек с радиусом 4000–9000
- **Около-Земные орбиты** — визуализация орбит спутников (опционально)
- **Ось Земли** — визуализация оси вращения с наклоном 23.44° (опционально)
- **Режимы камеры** — Земля, Луна, Солнце, свободный полёт
- **Скорость симуляции** — от реального времени до года за 60 секунд (логарифмическая шкала)
- **Пауза** — заморозка симуляции
- **Статистика** — время, дата, температура, фаза Луны в реальном времени

## 🚀 Запуск

### Вариант 1: Простой (локальный)

Откройте `index.html` в браузере (Chrome / Firefox / Edge 90+).

> ⚠️ ES-модули и import map требуют **HTTPS или `localhost`**. При открытии через `file://` браузер может заблокировать модули. Используйте локальный сервер:

```bash
# Python
python -m http.server 8000
# → http://localhost:8000

# Node.js
npx serve .
# → http://localhost:3000
```

### Вариант 2: Docker

```bash
docker run -d --name planet-earth -p 8080:80 -v $(pwd):/usr/share/nginx/html nginx:alpine
# → http://localhost:8080
```

## ⚙️ Технические детали

- **Движок:** Three.js r160 (через CDN `unpkg.com`)
- **Модули:** ES2022, импорт через `<script type="importmap">`
- **Камера:** `PerspectiveCamera(45°, 0.1–20000)`, OrbitControls с демпфированием
- **Скорость:** логарифмическая шкала, `SPEED_MAX = 525960` (год за 60 секунд)
- **Время:** `SECONDS_PER_DAY = 86400`, `SECONDS_PER_YEAR = 31557600`
- **Температура:** плавная интерполяция по месяцам (авто-режим)
- **Фаза Луны:** 13.4 орбиты за год (реальное соотношение)
- **Начальная позиция камеры:** `(0, 300, 900)`
- **Ограничения зума:** `minDistance=5`, `maxDistance=8000`

## 📐 Константы симуляции

| Константа | Значение | Описание |
|---|---|---|
| `SUN_R` | 109 | Радиус Солнца (у.е.) |
| `EARTH_R` | 1 | Радиус Земли (у.е.) |
| `MOON_R` | 0.273 | Радиус Луны (у.е.) |
| `ORBIT_R` | 500 | Радиус орбиты Земли вокруг Солнца |
| `MOON_DIST` | 60 | Расстояние Луны от Земли |
| `AXIAL_TILT` | 23.44° | Наклон земной оси |
| `SECONDS_PER_DAY` | 86400 | Секунд в сутках |
| `SECONDS_PER_YEAR` | 31557600 | Секунд в году |
